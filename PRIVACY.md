# Public release privacy

This public release contains application code, published PubMed article metadata/abstracts, and computed research results. It excludes the local Git history, personal name/student ID, private report PDFs, Canva edit links, local absolute paths, credentials, environment files and secrets.

The personal submission report is maintained separately. No API key is required to run the public app. Streamlit usage collection is disabled in config. Source records retain their PubMed URLs and copyright metadata; publication does not transfer source copyrights.
